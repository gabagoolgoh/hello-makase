  1. ☐ A1. tests/test_main.py: tests that posting Undo to a done to-do answers 303 to / and reloads it unstruck with its Done button back and no Undo, that the remaining count rises by one (including Nothing left to 1 left), that done then undo then done round-trips, and that undoing an already-open to-do leaves it and every other to-do unchanged (cases 1, 2, 3, 4, 6).

  4. ☐ A4. app/main.py: new POST /todos/{todo_id}/undo route that clears the to-do's done flag and answers 303 to /, and 404 for an unknown id, matching POST /todos/{todo_id}/done.
