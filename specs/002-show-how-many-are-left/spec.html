Done when

You open the to-do page in Test and, under the heading, it says how many to-dos are left, such as 4 left; adding a to-do makes the number go up by one.

What

Count the to-dos whose done flag is not set, which the Todo model in app/main.py already carries, and show the count on the page in a line of its own: N left, or 1 left for one and Nothing left for none. Done to-dos are not counted.

  • A TestClient test checks the page shows the count for the starter to-dos, and that adding one raises it by one.
  • A test sets every to-do done and checks the page says Nothing left.

Decisions

  1. Read the flag the model already has: this card does not depend on any other; it works whether or not a control to mark to-dos done has landed.
  2. Rendered on the server: the count is part of the page's HTML, so it is right on every reload with no client code.
